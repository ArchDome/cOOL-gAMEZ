# Announcer lines

Record each line as its own file and name it with the key (e.g. `homerun.m4a`). Shout it like a stadium announcer. Leave a little silence at each end; the script trims it.

| Key | When it plays | Suggested line |
| --- | --- | --- |
| `race` | Someone starts a race | "Race starting!" |
| `go` | Countdown hits zero | "GO!" |
| `bat` | You grab a baseball bat | "Bat acquired. Go get 'em." |
| `glider` | You grab a glider | "Glider online." |
| `homerun` | A bat hit lands (either side) | "HOME RUN!" |
| `dunked` | A friend knocks you into the sea | "Splashdown!" |
| `dunk` | You knock a friend into the sea | "Dunked!" |
| `splash` | You fall in on your own | "Man overboard!" |
| `swim` | A friend falls in on their own | "Somebody's swimming!" |
| `enemybat` | A friend grabs a bat | "They've got the bat. RUN!" |
| `finish` | You collect every spark | "Race complete!" |
| `pb` | New personal best | "New personal best!" |
| `final` | The final spark appears | "THE FINAL SPARK HAS APPEARED!" |
| `magnets` | Someone powers the junkyard magnets | "Magnets on!" |
| `erupt` | The volcano erupts | "The volcano is erupting!" |
| `gust` | Someone sounds the storm horn | "Hold on to your hats!" |
| `surge` | Someone overloads the transformer | "Power surge!" |
| `boulder` | A boulder or snowball is let loose | "Look out below!" |
| `missile` | A cruise missile crate drops | "A cruise missile has dropped!" |
| `missileaway` | You fire the missile | "Missile away!" |
| `lock` | A missile is locked on you | "Missile lock!" |
| `sniped` | You get sniped | "Sniped!" |
| `trickshot` | A spin-sniper hit | "TRICKSHOT!" |
| `finalgot` | Someone grabs the final spark | "What a finish!" |
| `streak` | Someone hits a kill streak (3, 5, 10, 15, 20, 25 in a row) | "On a roll!" |
| `shutdown` | A streak of 5 or more ends | "Shut down!" |
| `losing` | Someone hits a losing streak | "Taking on water!" |
| `nukeready` | You earn the nuke (30 in a row) | "Nuke ready!" |
| `nuke` | Someone drops the nuke | "Tactical nuke incoming!" |
| `minute` | One minute left in a round | "One minute left!" |

Missing clips fall back to the synthetic voice, so record as many or as few as you like. Names are shown on screen, so the clips don't need them.
